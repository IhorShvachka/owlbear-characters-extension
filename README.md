# Персонажі — розширення для Owlbear Rodeo

Перероблення з інструмента для токенів на інтерактивні листи персонажів ведеться в гілці `feature/interactive-character-sheets` та чернетці [PR #1](https://github.com/IhorShvachka/owlbear-characters-extension/pull/1). Зміни ще не опубліковані в GitHub Pages і не змінюють `main`.

## Реалізовано в гілці

- Аудит попередньої Vite + TypeScript архітектури.
- Імпорт JSON із перевіркою синтаксису та розміру файла.
- Попередній перегляд розпізнаних полів D&D 5e перед імпортом.
- Перелік персонажів для ГМ, призначення й перепризначення гравцям, відкриття та видалення листів.
- Лист із базовими характеристиками, HP, КЗ, ініціативою, швидкістю, навичками, спорядженням, заклинаннями, рисами та оригінальним JSON.
- Редагування бойових значень і нотаток власником листа або ГМ.
- Збереження в метаданих кімнати лише як тимчасова основа прототипу.

## Критичне обмеження приватності

Метадані кімнати Owlbear є спільними, а клієнт розширення отримує ці дані. Приховування листів у UI не є захистом: учасник із технічними знаннями може дослідити спільні дані. У цій версії **не можна гарантувати, що гравець не зможе прочитати чужий JSON**. Також метадані мають обмеження розміру, тому вони не підходять для повних листів. Перед реальною грою потрібен зовнішній сервер зі сховищем і авторизацією кожного запиту на читання та запис.

## Що ще потрібно зробити

- Запустити `npm run build` і виправити всі помилки компіляції.
- Протестувати реальні JSON-експорти D&D 5e, бо різні сайти використовують різні структури.
- Додати окремий захищений бекенд для приватного зберігання.
- Перевірити одночасне редагування двома клієнтами та реальну кімнату Owlbear.
- Лише після цього вирішувати питання злиття в `main` та публікації.

## Локальна розробка

```bash
npm install
npm run dev
npm run build
```
