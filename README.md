# Персонажі — розширення для Owlbear Rodeo

Окремий Vite + TypeScript проєкт розширення Owlbear Rodeo.

## Функції поточної версії

- Вибір токена з активної сцени.
- Призначення власника зі списку гравців кімнати.
- Збереження шаблонів у метаданих кімнати.
- Створення копії персонажа в центрі поточного перегляду.
- Синхронізація підтримуваних властивостей позначених копій на активній сцені.
- Узгодження зі збереженим шаблоном при активації сцени.
- Позиція, поворот і масштаб копій не синхронізуються.

## Розгортання

GitHub Actions збирає застосунок і публікує каталог `dist` у GitHub Pages при кожному push у `main`. У репозиторії відкрий **Settings → Pages** і перевір, що джерело розгортання встановлено на **GitHub Actions**.

Після успішного розгортання manifest доступний за адресою:

https://ihorshvachka.github.io/owlbear-characters-extension/manifest.json

## Додавання в Owlbear Rodeo

Скопіюй адресу manifest вище та додай її в каталозі розширень Owlbear Rodeo як власне розширення. Якщо сторінка ще не відкривається, перевір вкладку **Actions** і налаштування Pages.

## Обмеження й перевірка

Це рання версія, яку потрібно протестувати в реальній кімнаті Owlbear із кількома гравцями. Зокрема, слід перевірити, чи SDK приймає зміну `createdUserId` як очікуване призначення власника, і ввімкнути нативний дозвіл **Character → Owner Only**, якщо він відповідає потрібній поведінці.

Копії синхронізуються на активній сцені. Неактивні сцени узгоджуються, коли їх активують; миттєва синхронізація неактивних сцен не реалізована. Видалення шаблону не видаляє токени, які раніше були з ним пов’язані.

## Локальна розробка

```bash
npm install
npm run dev
npm run build
```
